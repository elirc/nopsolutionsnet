# 04 — Code Reading Gym

Reading code is a trained skill, and it's the one interviews test most directly (pairing screens, "walk me through this," review rounds). Four drill types, all against real code:

1. [01-annotation-drills.md](01-annotation-drills.md) — inputs/outputs/invariants/side effects on 8 real excerpts
2. [02-trace-tables.md](02-trace-tables.md) — follow a value through the layers, 5 traces
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 8 bad-vs-better pairs mirroring real repo patterns
4. [04-review-katas.md](04-review-katas.md) — 8 simulated PRs to review with graded findings

Rules of the gym: no skimming answers before attempting; grade yourself against the rubrics honestly; say answers *out loud* when the drill asks — interview fluency is a speaking skill, not a reading skill.
